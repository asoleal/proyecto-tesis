\chapter{Objetivo general}

Desarrollar un modelo matemático para predecir la generación de $CO_2$ durante la bioconversión de residuos orgánicos usando larvas de mosca soldado negra (\textit{Hermetia illucens}). Se utilizarán sensores IoT para medir variables clave como temperatura, humedad, concentraciones de $CO_2$, $CH_4$ y oxígeno, además de algoritmos de aprendizaje automático. Este trabajo busca optimizar la producción de gases de efecto invernadero, considerando las interacciones entre las larvas y los microorganismos, con el fin de mejorar la gestión de residuos y reducir las emisiones atmosféricas.

\textbf{Objetivos específicos:}
\begin{enumerate}
    \item Diseñar e implementar un sistema de adquisición de datos basado en sensores IoT para medir en tiempo real variables relevantes en el proceso de bioconversión, tales como temperatura, humedad, concentraciones de $CO_2$, $CH_4$ y oxígeno, facilitando el monitoreo continuo del sistema.
    
    \item Formular un modelo matemático que describa la generación de $CO_2$ a partir de las interacciones entre huevos de mosca soldado negra \textit{Hermetia illucens}, residuos orgánicos y condiciones ambientales, con el fin de predecir la producción de gases de efecto invernadero.
    
    \item Entrenar y validar algoritmos de aprendizaje automático, como redes neuronales o árboles de decisión, que permitan predecir la generación de $CO_2$ a partir de los datos recogidos por los sensores, complementando y mejorando la precisión del modelo matemático.
    
    \item Evaluar la precisión del modelo desarrollado mediante la comparación de sus predicciones con mediciones experimentales realizadas en condiciones controladas de laboratorio, ajustando y optimizando el modelo para su aplicación práctica en la gestión sostenible de residuos y la mitigación de emisiones atmosféricas.
\end{enumerate}
