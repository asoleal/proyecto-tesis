\section{objetivos específicos}

\begin{enumerate}[label=\Roman*.]
    \item Diseñar y construir un sistema de adquisición de datos IoT con hardware especializado que integre sensores de alta precisión para la medición en tiempo real de variables ambientales críticas (temperatura, humedad, iluminación) y emisiones de gases de efecto invernadero (GEI) durante la bioconversión de residuos orgánicos mediante la mosca soldado negra (Hermetia illucens), asegurando la recopilación continua de datos para la optimización del proceso.
    \item Desarrollar un dashboard para el almacenamiento, visualización, análisis y gestión de los datos recopilados por los sensores IoT, que permita el monitoreo remoto, la trazabilidad de emisiones de GEI y variables ambientales, y facilite la toma de decisiones para optimizar el proceso de bioconversión.
    \item Implementar y validar el sistema integrado en un entorno controlado, evaluando la precisión de los sensores en la medición de variables ambientales y emisiones de GEI, así como su impacto en la eficiencia del proceso de bioconversión y la reducción de emisiones, asegurando la fiabilidad y estabilidad del sistema.
    \item Implementar algoritmos de inteligencia artificial en el sistema de monitoreo para analizar datos en tiempo real y optimizar su eficiencia operativa.
\end{enumerate}
